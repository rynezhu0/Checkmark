# Checkmark

**Live Demo:** https://checkmarkproject.vercel.app/

Checkmark is a modern productivity application designed to help users organize tasks through multiple task lists, color-coded clipboards, hotkey functionality. Built with React, Vite, and Tailwind CSS, it provides a fast, responsive experience with all data stored locally in the browser.

## Features

- Create and manage multiple task lists
- Organize task lists into customizable, color-coded clipboards
- Rich-text editing for task list titles and descriptions
- Custom tags, due dates, start dates, and task status tracking
- Global search across every task and task list
- Drag-and-drop task reordering with multi-select support
- Undo and redo functionality
- Light and dark themes
- Persistent local storage with no account required

## Tech Stack

- **Frontend:** React, Vite
- **Styling:** Tailwind CSS
- **State Management:** React Context API + `useReducer`
- **Icons:** lucide-react
- **Date Utilities:** date-fns
- **Deployment:** Vercel

## Local Development

```bash
npm install
npm run dev
```
